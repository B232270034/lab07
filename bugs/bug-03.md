# BUG-03: API хоосон JSON хүсэлтийг амжилттай хүлээн авч байна

**Орчин:** Debian GNU/Linux 13, Node.js, localhost:3000.

**Урьдчилсан нөхцөл:** `node app.js` сервер ажиллаж байна.

## Дахин гаргах алхам

1. Терминал нээнэ.
2. Дараах командыг ажиллуулна:

   ```bash
   curl -i -X POST http://localhost:3000/api/books \
     -H "Content-Type: application/json" \
     -d '{}'
3. HTTP статус болон JSON хариуг шалгана.

**Хүлээгдэж байсан үр дүн:** Шаардлагатай талбарууд байхгүй тул сервер хүсэлтийг татгалзаж, алдааны хариу буцаана.

**Бодит үр дүн:** Сервер `HTTP/1.1 201 Created` болон `{"result":"OK","id":7}` буцаасан.

**Ноцтой байдал:** Major — хоосон хүсэлт амжилттай болсон нь өгөгдлийн баталгаажуулалт алдаатай байж болохыг харуулж байна.

**Олдсон аялал:** Saboteur — API-д буруу өгөгдөл илгээх.

**Нотолгоо:** `evidence/bug-03-curl.txt`

**Төлөв:** Дахин гаргаж баталгаажуулах шаардлагатай.
