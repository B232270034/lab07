# BUG-04: Хайлт том, жижиг үсгийн ялгаанаас хамаарч байна

**Орчин:** Debian GNU/Linux 13, Chrome, localhost:3000.

**Урьдчилсан нөхцөл:** Жагсаалтад `Clean Code` нэртэй ном байна.

## Дахин гаргах алхам

1. `http://localhost:3000` хаягийг нээнэ.
2. Хайлтын талбарт `clean code` гэж бичнэ.
3. **Хайх** товчийг дарна.
4. Хүснэгтэд гарсан үр дүнг шалгана.

**Хүлээгдэж байсан үр дүн:** `Clean Code` ном хайлтын үр дүнд харагдана.

**Бодит үр дүн:** `clean code` гэж жижиг үсгээр хайхад хүснэгт хоосон харагдсан.

**Ноцтой байдал:** Minor — хайлтын үр дүн том, жижиг үсгээс хамаарч, хэрэглэгч номоо олоход хүндрэл үүсгэж байна.

**Олдсон аялал:** Search.
