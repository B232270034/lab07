### Автомат тест ба хүний ажиглалт

Playwright ашиглан хоосон талбартай ном нэмэх, зөвшөөрөгдөхгүй он оруулах, хайлтын үр дүнг шалгах үйлдлүүдийг автоматжуулж болно. Автомат тест нь тогтмол шалгалтуудыг давтан хийхэд тохиромжтой. Харин дэлгэцийн харагдац, номын тоолуурын зөрүү, хэрэглэгчид ойлгомжтой эсэхийг хүн ажиглан шалгах нь чухал. Автомат тест бүх төрлийн алдааг илрүүлнэ гэсэн баталгаа байхгүй.
